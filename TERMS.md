# CompliPay - Terms of Use and Acceptable Use Policy

## 1. Purpose

CompliPay is a ZATCA-compliant e-invoicing API platform designed exclusively for **lawful business purposes** in the Kingdom of Saudi Arabia. This software facilitates compliance with ZATCA (Zakat, Tax and Customs Authority) electronic invoicing regulations.

## 2. Acceptable Use

### 2.1 Permitted Uses

- Generating compliant e-invoices for legitimate business transactions
- Submitting invoices to ZATCA for clearance (B2B) or reporting (B2C)
- Integrating with ERP/accounting systems for automated invoicing
- Testing and development in sandbox environments

### 2.2 Prohibited Uses

Users **MUST NOT** use this software to:

1. **Tax Fraud or Evasion**
   - Generate false or misleading invoices
   - Underreport or misrepresent taxable amounts
   - Create invoices for fictitious transactions
   - Manipulate tax calculations or VAT amounts

2. **Financial Crimes**
   - Money laundering or terrorist financing
   - Invoice financing fraud
   - Creating fraudulent documentation for loans or credit

3. **Identity Fraud**
   - Impersonate other businesses or individuals
   - Use fake VAT registration numbers
   - Forge digital signatures or certificates

4. **System Manipulation**
   - Bypass ZATCA validation rules
   - Tamper with invoice hashes or signatures
   - Modify QR codes to contain false information
   - Exploit vulnerabilities for unauthorized access

5. **Regulatory Violations**
   - Violate Saudi Arabian tax laws
   - Circumvent ZATCA compliance requirements
   - Use outside authorized jurisdictions without proper licensing

## 3. Compliance Requirements

### 3.1 User Obligations

Users must:

- Maintain valid ZATCA credentials and certificates

### 3.2 Data Accuracy

Users are solely responsible for:

- Accuracy of seller/buyer information
- Correctness of VAT registration numbers

## 4. Security Requirements

### 4.1 Credential Protection

Users must:

- Keep API keys and JWT tokens confidential
- Rotate credentials regularly (minimum every 90 days recommended)
- Never share production credentials
- Use HTTPS for all API communications
- Store private keys securely (encrypted at rest)

### 4.2 Access Control

Organizations must:

- Implement role-based access control
- Maintain audit logs of all invoice operations
- Monitor for suspicious activity
- Report security incidents within 24 hours

## 5. Audit Trail

- Invoice creation, modification, and submission
